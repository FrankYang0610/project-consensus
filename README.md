# Welcome to the _polyu.life_ Source Code Repository!

**polyu.life** (development project name: **project-consensus**) is a forum and course review community that serves students of The Hong Kong Polytechnic University.

We welcome developers, as well as students and faculty, to contribute features, bug fixes, refactors, chores, style improvements, and corrections to polyu.life. You may contribute to the project by submitting an issue, a pull request, or by starting a discussion.

Please use `git clone https://github.com/FrankYang0610/project-consensus` to clone the entire repository, after which you can review and edit it. Please refer to `/project-consensus-frontend` and `/project-consensus-backend`, which are the web frontend and backend of this project, respectively. More detailed documentation on development and deployment is available there.

This project began in the Fall of 2025.
